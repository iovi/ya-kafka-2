Приложение реализовывает отправку сообщений между пользователями. 

Каждый пользователь отправляет широковещательные сообщения (структура MessageDto) в топик "messages". Входящий топик у каждого пользователя разный, имеет вид filtered_messages_{id}, где id - идентификатор пользователя. Пользователю предлагается на него подписаться.

Имеются ограничения в топике blocked_users, из которого создан одноимённый state store. В качестве ключа в топике выступает ид. пользователя, который хочет кого-то заблокировать. В данный момент каждый пользователь может заблокировать только одного, т.о. значение в сообщениях топика - ид. заблокированного пользователя для данного. При необходимости можно доработать приложение на список заблокированных пользователей для каждого.

Список запрещённых слов заводится в приложении с помощью job\BadWordService. Джоб BadWordsSetter ежеминутно добавляет какое-то слово в заблокированные для демонстрации.


В приложении демонстрируется работа для 4х пользователей (количество настраивается в properties) 

Джоб job\Producer каждые 20 с выполняет рассылку по одному сообщению от имени каждого пользователя и выводит в консоль отправленные.

Джоб job\Consumer каждую секунду проверяет сообщения для всех пользователей и выводит в консоль полученные.

BlockedUsersProducerService - сервис для заполнения топика заблокированных пользователей тестовыми данными (2 блокировки пользователей) .

StateStoreService подготавливает state store для работы и вызывает BlockedUsersProducerService для его заполнения и выводит эти данные.


StreamsRunner реализует основную работу приложения Kafka Streams - перенаправляет данные из входного топика в выходные фильтруя сообщения от заблокированных пользователей и маскируя "плохие" слова.

В папке Serdes - классы необходимые для сериализации сообщений MessageDto

Требуется установленный docker и java 17+

Необходимо запустить docker-compose.yml с помощью команды "docker-compose.yml up -d"

После этого запустить jar файл командой "java -jar out/artifacts/ya_kafka_2_jar/ya-kafka-2.jar"
